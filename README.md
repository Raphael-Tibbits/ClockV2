# ClockV2
Crystal oscilator clock project

This project aims to create a 1s/year accurate clock, this is done with an ovenated crystal oscilator. 

There are two versions of the hardware, one with a discrete XO, which can be trimmed; and the other with a TCXO module that cant be trimmed

The hardware is made to be IEEE1101.3 compliant form factor as a 3U x 160 deep eurocard that occoupies 4HP. Mechanical stuff like a front panel is still to come.
